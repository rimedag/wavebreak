# Roadmap

Wavebreak is being developed in public from this alpha onward. This roadmap describes product themes, not promised dates. Items may change as the product matures and real usage reveals better priorities.

## Browser Foundation

- Everyday browsing reliability.
- Browser UX and polish.
- Permission, migration, download and session-restore improvements.
- Better compatibility with complex websites while keeping Electron isolation and web security enabled.

## Dynamic Mode

- More reliable transformations across articles, stores, media pages and web apps.
- Better handling of video players, embeds, image-heavy pages and edge-case layouts.
- Clearer controls for switching, revealing originals and understanding what each mode changed.

## Performance

- Memory and CPU profiling.
- Repeatable performance baselines before making public performance claims.
- Optimization work driven by measured bottlenecks.

Wavebreak does not currently claim to use less RAM than Chrome, Brave or other browsers.

## Stillpoint

- Refinement of the current Daily workspace.
- Deeper Stillpoint integration.
- Stronger shared Markdown workflows.
- A clearer path between browser notes, standalone notes and user-owned folders.

## Creative Workspace Integrations

- Void Room integration.
- Creative Pressure integration.
- Signal vs Noise integration.

These are future workspace directions, not alpha.6 features.

## Platforms and Distribution

- macOS build and validation.
- Linux build and validation.
- Android future mobile build work.
- iPadOS / iOS future mobile build work.
- Windows code signing.
- Update and distribution improvements.

No macOS, Linux, Android, iPadOS or iOS release is available today.

# Help shape Wavebreak

Useful contributions include reproducible bug reports, descriptions of unmet needs, documentation corrections and thoughtful discussion. Explain what you were trying to do and where the experience got in your way.

This public repository contains no application source. We do not accept application-code pull requests here. Documentation suggestions are welcome; do not include proprietary files, decompiled application material or content you do not have permission to share.

Use Issues for reproducible bugs and concrete feature requests. Use Discussions for Announcements, Ideas, General, Help and Stillpoint conversations once those categories are enabled.

Before posting, remove passwords, cookies, browsing history, personal notes, file paths identifying other people, and sensitive screenshots. Use a minimal example with made-up data whenever possible. Report vulnerabilities privately as described in SECURITY.md, never in a public Issue.

Treat other people respectfully. Product feedback is welcome; harassment and exposure of personal information are not.

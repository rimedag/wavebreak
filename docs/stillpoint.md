# Stillpoint

Stillpoint is Wavebreak's integrated thinking and note-taking direction: local-first, Markdown-first, built around files you can keep using in other tools.

## Available in the current alpha

The interface currently calls the optional notes area Daily. It provides dated local notes and folder organization, plus a separate shared Markdown editor. You can choose an existing folder, find and edit `.md` files, save new notes inside existing directories, reload files, and detect many conflicting external edits. Notes are unavailable in Private windows.

The shared editor works with ordinary UTF-8 Markdown, including text containing frontmatter or wiki links. It is a text editor, not a complete Obsidian-compatible renderer. Markdown-folder editing and internal Daily notes remain separate.

## Intended shared-folder workflow

Wavebreak, standalone Stillpoint and other compatible tools are intended to work on the same user-owned files. Wavebreak's folder editor exists; the current standalone notes application still needs its live-folder integration. Do not assume that its existing internal notes automatically synchronize.

## Planned

A standalone Stillpoint product, a public specification for additional note metadata, and touch-first iPad/iPhone experiences. Handwriting, drawing and native Apple Pencil integration on iPad are planned, not available today. No cloud synchronization service is included.

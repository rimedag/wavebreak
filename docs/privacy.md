# Privacy guide

See the [current privacy notice](../PRIVACY.md) for local storage, network requests, Private sessions and notes.

Practical habits: keep important files backed up, choose note folders deliberately, and remove sensitive content from support screenshots. Private browsing does not hide your IP address. Clearing browsing data does not erase notes, exports or files you downloaded.

Questions about policy can go to Discussions. Vulnerabilities must use the private channel in [SECURITY.md](../SECURITY.md).

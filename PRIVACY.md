# Privacy

This notice describes the current Wavebreak public alpha. It is not a promise of anonymity.

## Local Data

Wavebreak currently has no product account, no cloud sync and no in-app product analytics. It does not upload browsing content or note contents to a Wavebreak service.

Normal browsing can store settings, bookmarks, history metadata, restorable tab addresses, cookies, website storage, downloads and local cache data on your device. Restorable addresses can include search queries or other URL parameters.

The optional Daily workspace stores notes locally. The shared Markdown editor reads and writes `.md` files in a folder you explicitly choose.

## Network Activity

Visiting websites sends normal requests to those websites and their allowed resources. Submitting a search sends the query to the selected search provider. Media providers, websites and network operators may still observe your activity.

Wavebreak can download filter-list updates from public filter-list providers. These requests do not include your browsing history.

## Private Sessions

Private sessions use separate temporary browsing partitions and avoid saving normal session history. Downloaded files remain on disk. Private sessions do not make you anonymous and cannot remove traces outside the application.

## Notes and Files

Your files belong to you. If you store notes in a cloud-synced folder or open them in another app, that app or service has its own behavior and terms. Keep independent backups, especially during alpha testing.

## GitHub

Issues, Discussions and release pages are hosted by GitHub. Do not post passwords, cookies, private notes, browsing history or security vulnerability details publicly.

## Future Changes

No application analytics is currently implemented. Any future telemetry, sync or account feature should require an explicit product decision and an updated privacy notice before release.

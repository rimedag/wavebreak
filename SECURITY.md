# Security Policy

Wavebreak is currently alpha software.

Do not disclose vulnerabilities, exploit details, credentials, private browsing data or private note contents in public Issues or Discussions.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/rimedag/wavebreak/security/advisories/new

Private vulnerability reporting must be enabled on the public repository before this link is used as the official reporting channel. GitHub documents this feature for public repositories and repository administrators can enable it in repository security settings.

When reporting a security issue, include the affected Wavebreak version, operating system, a concise description of the issue, expected impact and safe reproduction steps using synthetic data.

Wavebreak does not currently offer a bug bounty program or guaranteed response time.
